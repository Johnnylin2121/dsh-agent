# Amazon Listing Skill — 使用指南(2026-07 新政策版)

## 简介

从竞品分析到 Listing 上架的完整工作流,遵守 **2026-07-27 生效的新标题政策**:
- 标题 ≤ **75 字符**(含空格),想展示商品亮点必须 < 75
- 商品亮点(Item Highlights)≤ **125 字符**(单字段,最多约 10 条属性短语)
- 标题+亮点合计 ≤ **200 字符**
- 亮点字段**可搜索**,且不重复标题已有信息

支持任意站点(.com/.co.uk/.de/.co.jp/.com.mx 等),自动适配语言风格。

---

## 触发方式

> "亚马逊 listing" / "竞品分析" / "关键词" / "标题五点" / "商品亮点" / "后台搜索词"

---

## 六步工作流(每步结束都会暂停等你确认)

### Step 0 — 确认站点与政策
默认用你提供的链接站点;确认产品类目适用 75/125/200(媒体类豁免,服装类标题 60)。

### Step 1 — 竞品数据 + 核心关键词 Top10
**抓取降级链**(DSH 无浏览器自动化,最多各试 2 次):
1. Jina Reader:`curl "https://r.jina.ai/https://www.<站点>/dp/<ASIN>"`
2. 直连 curl(带桌面 UA)
3. 都失败 → **你手动粘贴**竞品标题+五点(每竞品:标题一行,下面跟五点行)

**分析**:自动运行 `scripts/kw_analysis.py`(标题词×3 / 五点词×1,输出 1-gram/2-gram 排名),AI 再筛出 Top10 核心词。你审核是否为品类定义词(如 "Hub USB 7 Puertos",而非纯属性 "Aluminio")。

### Step 2 — 标题 ≤75 + 商品亮点 ≤125
- 标题:核心词前置(前 3-5 词),留 ≤73 余量(75 恰好不触发亮点展示)
- 亮点:**短语非句子**,`;` 分隔,≤125 总字符,**与标题逐词去重**
- ⚠️ 竞品高频词(HDCP/VRR/Dolby/认证等)若你的产品未证实支持,AI 会标 `[待确认]`,需你确认后才入文案

### Step 3 — 五点(5 条 × ≤500 字符)
每点一个卖点组;不照抄标题/亮点措辞,用换说法覆盖更多搜索意图。

### Step 4 — 后台搜索词(≤249 **字节**,非字符)
排除集 = 标题+亮点+五点全部词;只装没进排面的词:同义词/错拼/其他语言词/互补词/长尾。带重音的西语字符占 2 字节。

### Step 5 — 投放后回检(1-2 周后,广告联动)
用广告搜索词报告验证新标题核心词是否来量;高效未覆盖词 → 下次迭代进标题;旧长尾光花钱不转化 → 否定。

---

## 硬性规则速查

| 项目 | 限制 |
|---|---|
| 标题 | ≤ 75 字符(建议 ≤73) |
| 商品亮点 | ≤ 125 字符(合计,非每条) |
| 标题+亮点合计 | ≤ 200 字符 |
| 单条五点 | ≤ 500 字符 |
| 后台搜索词 | ≤ 249 bytes |
| 标题新禁字符 | ! $ ? _ { } ^ ¬ ¦ |
| 单词重复 | 标题内 ≤2 次(虚词除外) |
| 违禁内容 | 促销/价格/保修承诺/主观夸张/物流时效/联系方式 |

## 实战踩坑记录

1. **75 不触发亮点展示** → 标题永远留余量
2. **亮点是单字段 125 总预算** → 不是每条 125
3. **亮点与标题逐词去重** → 连 eARC/HDR 这类缩写也算重复,改用收益表达
4. **竞品声称 ≠ 你的产品支持** → 一律 `[待确认]`,确认了才写
5. **标题装不下所有词** → 承接顺序:亮点 → 五点 → 后台搜索词
