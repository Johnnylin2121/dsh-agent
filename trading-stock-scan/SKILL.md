# 个股深度扫描

> **定位（2026-09-28 重写）**：本 skill 聚焦**持仓逻辑验证**，不做全量基本面研究。
> 原版的公告抓取/机构评级/财务数据三节是纯搬运（90% 成本），且抓不到时用"自评"填坑
> 制造假权威——已砍掉。保留的三个节都有实际判断价值：
> ① 商品锚核验 ② 支柱增量对比 ③ 规则触发对照。

> **环境适配**：①每轮 ≤3 tool；无 `obsidian_*` → 文件工具写入。②会话内不重复重读本 SKILL；失败 1 次→减负单 call。

## 触发条件

用户说以下任一短语时触发：
- "深度扫描 XXX"
- "研究一下 XXX"
- "XXX 怎么样"
- "帮我看看 XXX"

仅手动触发，不在复盘或盘前预测中自动执行。

## 数据源

| 数据 | 来源 | 获取方式 |
|------|------|----------|
| 实时行情 | 东方财富 API | `dsh-market stocks` |
| 商品锚 | 新浪期货 | `dsh-market sina "nf_*/hf_*"` |
| K线 | 东方财富 | `dsh-market kline` |
| 板块资金 | 东方财富 | `dsh-market sector` |
| 事件核实 | web_search | 异动时必做 |

**砍掉的数据源**（2026-09-28）：
- ~~近期公告~~：纯搬运，无判断价值，且 `get` 返回空时用自评填坑
- ~~机构评级~~：常为空，空则自评替代 = 制造假权威
- ~~财务数据~~：纯搬运，需大量解析，且与持仓逻辑验证无关

## 执行流程

### Step 0: 时间校验

- 获取当前日期，确认扫描数据日期口径

### Step 1: 确定标的 + 模式判定

- 用户提供股票名称或代码；若提供名称，在 `{VAULT_PATH}/wiki/entities/` 中查找对应 entity 文件获取代码
- **模式判定**：
  - **首次扫描**：`wiki/entities/` 无该标的 `*-深度扫描-*.md` → 全量建档（商品锚核验 + 支柱基线 + 规则触发对照）
  - **增量复扫**：存在基线文件 → **先读基线**，输出聚焦：「基线 vs 现状」支柱对比 + 逻辑验证结论 + 规则触发对照

### Step 2: 获取数据（精简为 4 项）

> ⚠️ **本机 HTTPS 现状**：Windows schannel 出站 TLS 损坏，curl/Invoke-WebRequest 不可用；统一用 `dsh-market.mjs`（node.fetch/OpenSSL）。
> **每轮最多取 1–2 项**（≤3 tool），按下列顺序做完一项再进下一项。

1. **实时行情**：`node "$MK" stocks "{code}"` + `node "$MK" sina "sh{code}"` 交叉
2. **K线**：`node "$MK" kline "SH{code}" 101 30`——量价趋势、量价背离判断、关键位
3. **商品锚核验**：按 trading-daily-review 的「持仓商品锚映射表」抓对应期货；商品异动必须 web_search 核实驱动
4. **资金流向**：三层代理（板块资金 / K线量能 / Vault 复盘主力记录）

### Step 3: 整合分析

- **首次扫描**：建立支柱基线（每个支柱 ✅/⚠️/❌ + 证据）
- **增量复扫**：核心结构 = 「**逻辑支柱状态 × 时间**」对比表 + 变化证据链 + **结论：持仓逻辑是否变化**

### Step 4: 关联现有持仓 + 规则触发对照

读取 `{VAULT_PATH}/交易体系/03.交易计划/当前持仓.md` 及对应 `*-操作规则.md`：
- 若标的在持仓中 → **逻辑支柱表** + **规则触发对照表** + 标注当前逻辑状态与变化
- 若标的在待入场计划中 → 标注入场条件完成度变化
- 若不在持仓/计划中 → 标注"观察中"

### Step 5: 写入文件

输出路径：`{VAULT_PATH}/wiki/entities/{股票名}-深度扫描-{YYYY-MM-DD}.md`

## 格式规范

- 数值保留2位小数
- 使用 Obsidian 兼容的 Markdown 语法
- frontmatter 中 `related` 必须链接到对应的 entity 文件；**复扫必须含基线链接**
- 复扫文件命名：`{股票名}-深度扫描-{YYYY-MM-DD}.md`（不覆盖：保留历史，新日命名）
- **抓不到数据时留空并标注"无数据"，禁止用自评填坑制造假权威**
