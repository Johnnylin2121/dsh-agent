# 优化潜力评估清单（P3 产品定位扩展模块）

> 目的：在四象限（明星/问题/潜力/淘汰）之外，回答"这个产品有没有值得尝试的优化空间"。
> 适用：销量低或中等的产品，判断是否应拉入**潜力组**投入资源，还是维持/放弃。

## 评估流程

```
输入：单个 ASIN 的 28 天汇总 + W4 数据 + 搜索词 Top 词根
→ 1. 静态定位（四象限/五档基础分类）
→ 2. 优化潜力评分（下表逐项勾选）
→ 3. 结论：可尝试 / 谨慎 / 不建议
```

## 潜力判据（满足 ≥2 项 → 潜力组）

| # | 判据 | 数据来源 | 说明 |
|---|------|----------|------|
| 1 | 低销量 + 低 ACOS（<35%） | 产品表现汇总 | 卖不动但花得少，缺的是流量不是效率 |
| 2 | CVR 低于店铺平均，且**有明确提升抓手** | 产品表现 + 覆盖分析 | 如高效词未覆盖标题、主图信息不足等 |
| 3 | 广告结构单一（如仅 SP 自动，无手动/定位） | 广告表现文件 | 有未开发的流量结构 |
| 4 | 存在高 ACOS 词可否定（浪费≥$3） | 搜索词报告 | 提纯后 ACOS 下降空间明确 |
| 5 | 关键词覆盖缺口（盈利词未进标题/五点） | 覆盖分析输出 | Listing 优化 ROI 高 |
| 6 | 周趋势向上（W4 > W3 订单） | 周趋势分析 | 处于爬坡期 |

## 反证（满足任一 → 不建议投入，维持或淘汰）

| # | 反证 | 说明 |
|---|------|------|
| 1 | 高 ACOS（>50%）且自然订单=0 | 纯广告驱动且亏损，结构性问题 |
| 2 | 低销量且 CVR 远低于店均（<店均×0.5） | Listing 本身转化力差，广告难救 |
| 3 | 无评论/评分明显低于竞品 | 信任缺失，优化难以短期见效 |
| 4 | 数据期无任何曝光、无搜索词数据 | 市场无需求信号 |

## 输出

```markdown
| ASIN | 静态定位 | 潜力判据命中 | 反证命中 | 结论 | 建议动作 |
|------|----------|--------------|----------|------|----------|
| B0DZCFQ3FH | 待评估 | 1,3,5,6 | 无 | 可尝试 | 增加广泛预算+补关键词覆盖 |
```

> 注：潜力组的资源投入应设验证窗口（2-4 周），到期未达标降级为"谨慎"，避免沉没成本。
