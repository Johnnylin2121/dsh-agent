# 实时矛盾检测

> **环境适配（2026-09-22）**：①每轮 ≤3 tool；write 与 task 分轮，禁止捆绑。②终值/复盘已在上下文则不重拉、不重读本 SKILL。③失败 1 次→减为单 call 或文字汇报。④本 skill 不使用 `xueqiu_*`（交易政策永久禁用）；若需交叉校验行情，用东财+新浪+dsh-market。

## 定位

与 `obsidian-reconcile` 互补：
- **obsidian-reconcile**：定期全 vault 扫描，发现长期积累的矛盾
- **本 skill**：每次复盘自动执行，聚焦近3日数据的即时矛盾检测

## 触发条件

- 盘后复盘时自动执行（作为复盘流程的一部分）
- 用户说"检查矛盾"、"有没有前后矛盾"

## 执行流程

### Step 1: 收集比对数据

> ⚠️ **锚点必须按标题文字匹配，不要按章节号。**
> 章节号会随复盘模板演进而漂移——历史上按 §十二/§八/§五 取内容，
> 而 2026-09-16 之后的实际复盘是 §十一/§七/§三，**导致 09-16～09-24
> 连续 5 天输出「检出矛盾 0 条」：不是市场没矛盾，是根本没读到内容。**
> 任何锚点定位失败都必须显式报出，见下方「锚点自证」。

**锚点表**（2026-09-30 重写。教训：锚点**不能绑定章节标题或章节号**——复盘模板每
换代一次，标题与编号就整体漂移（09-23/24 是「大盘与量能/持仓收盘」，09-28 换成

现改为**按内容关键词匹配**：命中判定 = 全文出现该行任一关键词（子串即可，
先剥离行首的 `一、`/`〇、`/`七之二、` 编号与 emoji 装饰）。）

#### 锚点自证（强制，不得省略）

在执行四维检测**之前**，先输出一段定位报告，格式固定：

```
锚点定位：命中 N/8（前日）/ M/8（当日）
- 可验证假设: ✔ 13、可验证假设
- 量能判断: ✔ 一、指数与量能
- 板块判断: ✔ 七、板块表现
- 持仓数据: ✔ 二、持仓
- 核心驱动: ✔ 〇、今日一页速览
- 连贯性自检: ✔ 六、连贯性验证
- 明日关注点: ✔ 九、明日关注点
- 校准账本: ✘ 该篇为简版，无此节
```

**规则**：
- 命中判定按上表的**关键词**做，结果里**写出实际命中的那一行标题**（便于事后核对规则是否仍贴合模板）。
- 任一锚点 `✘` 时，**必须在最终结论里点名**，并写明因此**哪些维度未能检测**。
  若判断为「该篇为简版，无此节」，注明即可，不算失败。
- **命中 0 个锚点时，禁止输出「检出矛盾 0 条」**——应判定为检测失败并中止。
- 「检出矛盾 0 条」只有在核心锚点（可验证假设 / 量能 / 持仓 / 核心驱动）全部命中的前提下才允许出现。
  这条是本技能 2026-09 静默失败 5 天的直接教训，不得再省。
- **连续两次运行若发现锚点命中率下降**，说明模板又换代了——此时按当日实际标题
  补充关键词，并回写本表。锚点表是会腐烂的资产，不是写一次就一劳永逸的。


### Step 2: 执行四维检测

**维度一：预判 vs 实际**
- 从前日复盘"可验证假设"中提取每个假设的验证标准
- 对比当日复盘中的实际数据
- 标记偏差 > 5% 的预判为矛盾
- 偏差 2%-5% 标记为偏离（⚠️）
- 偏差 < 2% 标记为一致（✅）

**维度二：板块判断连贯性**
- 提取近3日复盘中对同一板块的判断
- 检测是否存在以下模式：
  - 前日"看多"→ 今日"看空"，但未说明转变原因
  - 前日"领涨"→ 今日"弱势"，但无归因分析
- 不算矛盾的情况：明确引用了新数据/新事件说明转变

**维度三：持仓逻辑一致性**
- 读取 `交易计划/` 下各持仓标的计划文件的"决策依据/失效条件"状态（Step 1.4 已收集）
- 对比当日复盘中对该标的所属板块的判断
- 矛盾模式：
  - 复盘称"XX板块承压"，但该板块持仓逻辑仍为 ✅
  - 复盘称"XX板块走强"，但该板块持仓逻辑已为 ❌

**维度四：量能判断一致性**
- 对比近3日的量能状态描述（确立/试探/萎缩）
- 检测是否存在状态跳跃但缺乏过渡说明
- 例如：前日"萎缩"→ 今日"确立"，但成交额变化不足 15%

**维度五：今日判断 vs 记忆先例对照（2026-09-07 立，2026-09-07 晚修正定位）**
- 将当日复盘/盘中验证中的关键判断与 `00-交易记忆总表.md` A/B/C 区"当前有效版本"逐条比对
- 偏离模式示例：
  - 当日把"放量"直接等同于"反弹确认" → 偏离 A2 量能判据 v2（放量+收高双条件）
  - 当日对单日爆量板块给出追入倾向 → 偏离 B1 二日游（T+1 熄火 2/3）
  - 当日判断"恐慌"但量能缩量 → 偏离 A3（恐慌=放量+1:5 双条件）
  - 当日加仓评估忽略弹药预算 → 偏离 C9 弹药先行
  - 当日动作依据"盘中触线" → 偏离 C1 收盘口径第一性
- 输出：偏离条目 + 总表实证次数 + 历史案例链接 + 适用性提示
- ⚠️ **定位声明（记忆 = 先验参考，非裁决标准）**：记忆是历史归纳，不确保对任何新情况都适用。偏离记忆 ≠ 犯错——两种可能：①无意识重蹈覆辙（记忆救场）②**市场结构已变，旧模式失效（记忆需要演化）**——A4 绝对量能门槛在低量能时代失效即活例。判定权在当下数据与人工复盘，不在记忆。偏离 + 当下数据支撑且逻辑自洽 → 标记为"潜在新模式"，走记忆演化流程（增量更新 → consolidate 五类归因），而非强制服从记忆

### Step 3: 生成检测报告

输出格式（嵌入当日复盘报告）：

```markdown
## 矛盾检测

### 市场层矛盾 (X条)

1. **[类型标签] 简要描述**
   - 来源: [[文件链接]] §章节
   - 矛盾内容: 具体对比
   - 建议: 如何处理

### 方法层矛盾 (Z条)
> 自身流程出错（如盘中快照被写成收盘终值、时间戳错位、数据源混用）——与市场判断对错无关，是检测器/流程自身的缺陷信号。**方法层矛盾优先级最高**：它意味着当次产出的可信度需要重新评估。

1. **[类型标签] 简要描述**
   - 来源: [[文件链接]] §章节
   - 问题: 具体描述
   - 建议: 如何修复流程

### 偏离提醒 (Y条)

1. **[类型标签] 简要描述**
   - 来源: [[文件链接]] §章节
   - 偏离程度: 具体数据
   - 建议: 关注但无需立即处理

### 无矛盾项
- 预判验证: ✅ X/Y 通过
- 板块判断连贯: ✅
- 持仓逻辑一致: ✅
- 量能判断连贯: ✅
- 记忆先例对照: ✅（偏离 N 条待人工裁决）
```

类型标签：
- `[预判偏差]` — 假设验证不通过
- `[板块翻转]` — 板块判断前后矛盾
- `[逻辑不一致]` — 持仓逻辑与板块判断矛盾
- `[量能跳跃]` — 量能状态突变无说明
- `[记忆偏离]` — 当日判断与记忆先例不一致（维度五，附实证次数与历史案例；**偏离 ≠ 违规**，需人工裁决是重蹈覆辙还是市场结构已变）

### Step 4: 后续处理

1. **矛盾项**：强制要求在复盘「思维引导：必问问题」节回应——预判错误落到第2题「前几日预判，哪些错了？」，意外情况落到第3题「今天有什么是我没预判到的？」
2. **逻辑不一致**：报告提醒用户审查对应标的计划文件（`交易计划/标的-方向-计划名称.md`）的逻辑状态，不自动改文件
3. **偏离项**：记录但不强制处理

## 边界规则

- 只检测近3个交易日的数据，不做长期追溯
- 板块判断转变有明确新数据/新事件支撑的，不算矛盾
- 预判偏差 < 2% 的不标记
- 不自动修改任何文件，只生成报告和提醒
