# 领域记忆集成指南

如何在现有 skill 中集成 domain-memory。可集成（见下表已集成清单）——当前已集成：trading-daily-review。

---

## 集成模式

```
[Skill 入口] → 加载记忆 → [Skill 主体工作流] → 写入记忆 → [Skill 出口]
                    │                              │
                    └── 用户无感知，自动完成        └── 询问用户，可选
```

---

## 一、trading-daily-review 集成方案

### 入口修改（阶段一：盘前准备 → 前置动作）

在"前置动作"中插入记忆加载步骤：

```markdown
### 记忆加载（自动执行，新增）

1. 调用 domain-memory 检索工作流，参数：
   - domain: trading
   - last_n: 5
   - tags: 从当前市场状态推断（如量能状态、关注板块）
2. 将检索结果作为"历史记忆参考"注入盘前预测
3. 在盘前预测报告中增加"📋 历史记忆参考"章节，列出最近 3 条高置信度记忆
```

### 出口修改（阶段三：盘后复盘 → 步骤 3 之后）

在"归档清理"之后插入：

```markdown
### 4. 记忆写入（可选，询问用户）

1. 生成今日复盘的关键发现摘要：
   - 今日偏差（思维引导 Q3 的回答）
   - 规则修正（如果有）
   - 关联的持仓
2. 询问用户："今天的复盘有什么要记入交易记忆的吗？"
3. 如果用户同意，调用 domain-memory 写入工作流，预填：
   - domain: trading
   - 预测/假设: 从复盘报告的"前日复盘回顾"章节提取
   - 实际结果: 从"今日验证"章节提取
   - 偏差分析: 从"思维引导 Q3"提取
   - 规则修正: 如果有，从"矛盾检测"章节提取
```

## 二、集成后效果示例

### 场景：用户说"复盘"

```
1. trading-daily-review 被触发
2. 入口处自动加载 5 条交易记忆 ✓
3. 用户看到：
   [系统] 加载了 5 条交易记忆，其中 2 条涉及量能判断
   [系统] 活跃规则：右侧交易优先、量能<2.5万亿谨慎
4. 盘前预测完成
5. 盘中验证完成
6. 盘后复盘完成
7. 出口处询问：
   [系统] 今天的复盘有 1 个新发现：左侧交易风险需警惕
   [系统] 要记入交易记忆吗？(y/n) 
```
