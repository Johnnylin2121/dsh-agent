# 早读复核 (briefing-review)

> **环境适配（2026-09-22）**：①每轮 ≤3 tool；write/task 分轮，禁止捆绑。②会话内不重复 read 本 SKILL；数据已在上下文不重拉。③失败 1 次→减负单 call。④不使用 `xueqiu_*`（交易政策永久禁用）；web_search/交叉源缺失时标注覆盖范围外，不假填。

## 定位与权限边界（硬约束）
- 对人工正式早读（`交易体系/01.财经早读/YYYY-MM-DD-财经早读.md`）做第三方审阅
- **唯一输出**：`交易体系/09.新闻资讯/早读复核/YYYY-MM-DD-早读复核.md`（一份文件）
- **永不修改/回写正式早读**；vault 写入仅限 `交易体系/09.新闻资讯/早读复核/` 文件夹（2026-09-08 改名、2026-09-24 补 `09.` 编号前缀；用户解禁前有效）
- 审阅姿态：**不反驳、不支持、不生成新观点**，只做客观标注；人工正式早读的修订权在用户

## 触发与前置
- 用户说"复核早读 / 早读复核"，在正式早读入库后**手动触发**
- 前置检查：正式早读文件存在（不存在则停止并告知）；自动层文件（同日 `交易体系/09.新闻资讯/早读复核/YYYY-MM-DD-财经早报-自动草稿.md`）与 RSS 简报（`交易体系/09.新闻资讯/早读复核/rss-digest/digests/同日.md`）存在则一并加载，缺失则在报告中注明
- **历史兑现率（2026-09-28 立）**：读 `交易体系/08.校准账本/00-校准总览.md`（盘前执行时可能尚未生成——首次生成=前一日 15:10 定时任务）。存在 → 把累计命中率 + 近 5 日趋势写入报告第二节；不存在 → 标注「校准账本未生成」，**禁止静默跳过**

## 输出模板（三节，单文件）

```
# 早读复核 - {日期}
> 复核基准时点：开盘前（09:15）可得信息 · 复核执行时间：{timestamp}
> 复核覆盖率：行情表 {n}/{m} 项 · 事实类 {k}/{t} 项（web_search 核查）
> 覆盖范围外（不判定对错）：主观解读、docx 独有非公开信息（此部分走第二节记忆审阅）

## 一、数据复核（四态判定）
| 正式稿项 | 正式稿值 | 自动层/检索值 | 判定 | 说明（含时点标注） |

## 二、主观判断的客观审阅（逐条三态标注）
## 三、盲区标记（≤3 条）
```

### 四态判定规则（第一节）
- `一致`：偏差 <0.5% 或完全相符
- `口径差异`：时点/口径可解释（自动层=最近两根日线收盘 vs 正式=15:00→次日6:30），**不算错误**
- `过时-需修正`：正式稿发布时无误，但以开盘前最新信息看已变化 → 附最新值+时间戳（哪怕不是错误也要修正）
- `疑似错误`：超出时点可解释范围且无法解释 → 给出证据与建议核实方向
- 每项必须带时点标注；复核若在盘中/盘后执行，禁止用盘中数据倒推正式稿"错误"（基准=开盘前）

### 记忆审阅规则（第二节，硬约束）
**记忆依据单一事实源（2026-09-09 用户立法）**：第二节记忆审阅的唯一依据 = `交易体系/07.交易记忆/00-交易记忆总表.md`（用户定期沉淀交易记忆并归纳更新该表）。
- 引用格式：条目编号 + 实证次数 + 版本日期（如 `B1 · 5次实证 · 2026-09-07 版`）
- 总表未覆盖 → `【记忆-无覆盖】`，**不去散翻记忆归档/其他记忆文件补**（总表是浓缩裁决版，归档仅溯源用）
- 使用边界遵循总表头部立法：记忆=先验参考非裁决标准；实证次数=样本量；与当下数据冲突时当下优先，偏离显式标注走演化流程
- 复核时若发现总表版本滞后（已知重大事件/新规则未归纳），仅在报告尾注提示"总表可更新"，不代写
- 记忆**写入**（沉淀新教训）仍走 domain-memory 工作流与盘后第 5 步，与审阅依据分离
- **历史兑现率反馈（2026-09-28 立）**：读 `交易体系/08.校准账本/00-校准总览.md`，把累计命中率 + 近 5 日趋势作为主观判断的先验参考写入报告。命中率 20 条以内不具统计意义，只作趋势参考；账本不存在 → 标注「校准账本未生成」，禁止静默跳过

### 政策事件核验（2026-09-28 立，trading-policy-impact 并入）
正式早读涉及重大政策/事件时，逐条标注：
- `【政策-一致】` / `【政策-冲突】`：对照 `00-交易记忆总表.md` 中政策相关记忆（如农业题材政策高压线），附条目编号 + 实证次数
- `【政策-无覆盖】`：明说无覆盖，禁止硬套类比
- 重大政策判定标准：国务院/央行/证监会/发改委核心部委发布、行业性政策调整、地缘政治事件、宏观数据超预期、重大产业事件
- **不自动改写正式早读**；政策追踪文件的建立/更新走原 policy-impact 工作流（`wiki/topics/{政策名}-政策追踪.md`）

对正式稿中的主观判断逐条标注，只允许三态：
- `【记忆-一致】` / `【记忆-冲突】`：必须附记忆条目路径与沉淀时间（domain-memory 交易领域检索）
- `【记忆-无覆盖】`：明说无覆盖，禁止硬套类比生成新观点

记忆无覆盖时的**常识辅助**（约束）：
- 强制标签 `【常识-非记忆】`，与记忆引用明确区分
- 仅两类用途：① 事实性 sanity check（数字加总、因果链硬伤才出手）② 标注"偏离市场共识的程度"——**不评对错**，反共识本身当信息呈现（提示"此处与市场共识相反，是有意还是疏忽请自查"）
- 禁止用市场平均观点否定用户的独立判断
- 常识判断连续多次与后续复盘结论相反 → 反向沉淀为交易记忆（负样本），该类常识让位

### 盲区标记规则（第三节）
正式早读未提及、但同时满足以下两条的信息：
- 六类关注方向命中：商品 / 存储AI / 美股宏观 / 地产银行 / 地缘 / IPO打新
- 显著性阈值：商品单日涨跌 >2%、指数新高/新低、利率关口（如 30Y 破 5%）、政策落地、地缘升级
- **最多 3 条**；候选超过 3 条 → 判定阈值过松，先收紧阈值再输出
- 每条附：为何重要 + 跟踪字段（后续 3 日是否成为正式早读主题/盘面主线：命中/未命中）

## 定期校准（🔴 必填 · 每 10 个交易日或并入周度复盘）
> **不是建议，是必做。** 跳过校准 = 阈值漂移无人发现。

- 回看历史复核文件第三节，统计盲区命中率；命中率低 → 修改本 skill 阈值定义（注明调整日期与依据，版本化）
- 同时统计第一节的误报率（把口径差异误判为疑似错误的次数）
- 校准结果写入报告尾注（校准日期 + 命中数/总数 + 是否调整阈值）

## 与其他 skill 的分工（消歧）
- `trading-briefing-fetch`：只产出自动层数据文件（本 skill 的输入之一）
- `trading-contradiction-check`：跨日逻辑矛盾（前日预判 vs 实际）；本 skill 管当日事实核验
- `obsidian-reconcile`：全 vault 扫描；本 skill 只看当日早读
- `domain-memory`：记忆读写走其工作流；本 skill 只读引用（审阅用），产出教训时经由其写入工作流
