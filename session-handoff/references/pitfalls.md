# 交接坑库（累积式 · 域无关）

> **每次执行 `session-handoff` 必须更新本文件。**
> 接手方启动时必读——这是"上个会话踩过什么"的唯一传承载体。
>
> **本文件不预设领域。** 上半部分是交接工作流自身的通用坑；下半部分留空，由各会话/各领域 agent 追加本领域实际踩到的坑。

---

## 通用坑（跨领域恒成立）

### 交接类

| # | ❌ 错 | ✅ 正解 |
|---|---|---|
| H-01 | 交接书写成"现状汇报"，没有下一步 | 「当前位置」必须是接手方能立即执行的具体动作 |
| H-02 | 未决问题只列问题，不给可选项 | 每项给可选项 ＋ 回执格式，让对方能一句话答复 |
| H-03 | 用对话记忆里的数值 | 记忆里的值可能已过期 → **去读证据文件** |
| H-04 | 把交接全文贴进新对话 | 优先只给路径；对方读不到文件时才贴全文 |
| H-05 | 交接书塞进领域假设与预设结论 | 交接只记录**实际发生的**，不写"应该会怎样" |
| H-06 | 上下文被压缩后凭残存印象补写 | **主动回读证据文件**重建事实，不靠印象 |
| H-07 | 漏写"本会话 agent 的错误" | 判错记录是防重复的唯一依据，必须诚实写 |
| H-08 | 规则只写编号不给释义 | 接手方可能没读过原文，**必须给释义** |
| H-09 | 留痕时照搬别的系统的规范 | 以**目标系统自己**的规则为准 |
| H-10 | 交接书"看起来完整"但有编造内容 | **宁缺勿造**——无内容写"本会话无"并删节；编造比留空危害大 |

### [wiki-01] OneDrive mtime 导致 edit 工具失败
- **类别**：流程环境
- **时间**：2026-09-29
- **❌ 错**：使用 `edit` 工具修改 OneDrive 中的文件，报错 "file changed since it was read"
- **✅ 正解**：使用 pwsh 脚本直接修改文件，避免 `edit` 工具的 mtime 检查
- **📌 是否已制度化**：未立规则

### [wiki-02] PowerShell 正则表达式捕获组问题
- **类别**：数据工具
- **时间**：2026-09-29
- **❌ 错**：在 PowerShell 双引号字符串中使用正则表达式 `-replace`，捕获组 `$1` 导致文件被写空
- **✅ 正解**：使用 pwsh 脚本直接操作文件内容，避免复杂的正则表达式替换
- **📌 是否已制度化**：未立规则

### [wiki-03] 相似度百分比误导
- **类别**：判断纪律
- **时间**：2026-09-29
- **❌ 错**：仅根据相似度百分比（>40%）判断文件可合并，未读取内容
- **✅ 正解**：先完全读取内容进行复核，再判断是否可合并
- **📌 是否已制度化**：未立规则

### [trade-01] 量能推算错误
- **类别**：数据工具
- **时间**：2026-09-29
- **❌ 错**：14:56两市1.38万亿，推算全天1.25万亿（用均匀分布假设）
- **✅ 正解**：14:56已1.38万亿，距收盘4分钟，全天约1.38-1.40万亿
- **📌 是否已制度化**：未立规则

### [trade-02] 科技链判断错误（线性外推单日资金）
- **类别**：判断纪律
- **时间**：2026-09-29
- **❌ 错**：9/28判"科技链不参与"，9/29强势回流
- **✅ 正解**：单日大幅流出后，次日可能反弹（超跌反弹）→ 不线性外推单日资金
